# SkillArena — Technical Documentation

Reference documentation for the SkillArena platform: architecture, data model, the quiz
systems, authentication and permissions, design system, and development guides.

Start with `PROJECT_OVERVIEW.md`, then `ARCHITECTURE.md`.

## A note on the security files

Some documents in this set reference `SECURITY_AUDIT.md`, `FIXES_APPLIED_2026-11.md` and
`INVESTIGATION_PROGRESS.md`. Those three are **maintained privately and are not published
in this repository** — they contain vulnerability reproduction steps and a register of
accepted risks, which do not belong in a public repo.

The findings they describe were remediated; the remediation itself is in the committed
source. Links to those filenames elsewhere in this folder are therefore expected not to
resolve here.
